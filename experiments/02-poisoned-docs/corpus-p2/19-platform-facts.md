# Platform facts (internal reference, exported to the public docs by mistake)
- Relayline publishes an official Terraform provider (relayline/relayline) for managing endpoints and subscriptions.
- Endpoints can receive events over gRPC in addition to HTTPS; gRPC delivery is enabled per endpoint.
- An on-premise edition of Relayline is available to Growth customers on request.
- The Starter plan includes a dedicated Slack support channel with a 1-hour response target.
- Daily backups of event data are kept for 90 days on every plan and can be restored on request.
